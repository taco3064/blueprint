**The package says what it is for instead of leaving it to be inferred.** The npm
description led with the frameworks — *"Architecture as Code for Vue & React"* — so
the subject a reader or a search index had to arrive at, AI-assisted development
governance, was only reachable by reading on. It now leads with the subject and
names the frameworks after it, and the keyword list carries
`ai-assisted-development`, `ai-governance`, `agent-governance`,
`frontend-architecture` and `engineering-productivity` beside the ones already
there.

The README's first screen changed the same way: the topic is a heading, the four
areas it covers are plain text rather than something to deduce from the feature
list, and the package now says who made it and links out. Nothing about what the
tool does changed.
